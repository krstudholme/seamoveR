This package is designed to facilitate archiving and maintaining ECCC waterbird tracking data on Movebank. 

This is a work in  progress, but will ultimately include vignettes with step-by-step instructions for project creation and maintenance, as well as templates and guides to ensure standardization of column names and units. To simplify and standardize tracking data uploaded to Movebank, functions will be available for a range of common tag types and manufacturers. There will also be functions to generate a standard project README file and summarize multiple projects into a single-species PDF report. 

You can install the main version of seamoveR from [GitHub](https://github.com/) with:

```{r}
install.packages("devtools")
devtools::install_github("krstudholme/seamoveR")
```
